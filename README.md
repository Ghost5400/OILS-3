## 💡 What is OILS-3?

**OILS-3** (*Oops, I Learnt Something! — 3rd Sem Engineering, An Interactive Game to Crack Your Labs*) is an empathetic, pedagogy-first learning companion built specifically for **3rd Semester Computer Science & Engineering students** (VTU 2025 Scheme & allied universities).

Instead of confusing code dumps, high-stress pressure, or disconnected textbook PDFs, this companion provides a warm, step-by-step environment to truly understand the core principles, memory models, and exam questions across all three 3rd semester labs:

```
OILS-3/
├── 📜 open_me.txt            <-- Complete launch instructions & VTU 2025 scheme catalog
├── 📜 about_us.txt           <-- The story, creators (Prajwal & Aditya), and student manifesto
├── 🚀 play.py / play.bat     <-- Cross-platform terminal launchers (Windows, Mac, Linux)
├── 🐚 play.sh                <-- Native bash launcher for Mac, Linux & Mobile Termux
├── 📁 arcade/                <-- Pedagogy engines (DSA, Java, Git, Viva Bank, Memory Sandboxes)
│   ├── core.py               <-- Terminal UI styling, animated banner & dynamic MCQ shuffling
│   ├── dsa/                  <-- 12 DSA experiments, interactive ASCII sandboxes & disasters
│   ├── java/                 <-- 10 Java experiments, OOP visualizers & disasters
│   └── git/                  <-- 12 Git experiments, command arena, sandbox & question bank
├── 🌳 dsa-lab/programs/      <-- 12 Verified VTU C Programs (1BCS304)
├── ☕ java-lab/programs/     <-- 10 Verified VTU Java Programs (1BCS302)
├── 📚 docs/                  <-- Curated handbooks, git cheatsheets and guides
│   ├── GIT_REFERENCE.md      <-- The plain-English zero-jargon guide
│   ├── GIT_COMMANDS.md       <-- The complete command reference
│   └── GIT_CHEATSHEET.txt    <-- Quick syntax reference
└── 📦 archive/               <-- Historical monolithic engines
```

  - ⚡ **V7: QuickSort In-Place Partitioning:** Lomuto two-pointer scan, pivot settling into permanent slot.
  - 🔀 **V8: MergeSort Divide & Conquer Tree:** Recursive splitting down to single elements and 2-way sorted merge.
  - 🌲 **V9: Binary Search Tree (BST):** Invariant `Left < Root < Right` and Inorder sorted output guarantee.
  - ⚖️ **V10: AVL Tree Rotations:** LL Right, RR Left, LR Double, and RL rotations with balance factors.
  - 🔑 **V11: Hash Table Collision Resolution:** Linear probing, clustering, and tombstone markers.
  - 🕸️ **V12: Graph Traversal Stepper:** Queue-driven BFS vs Stack-driven DFS side by side.
  - 📦 **Interactive Stack & Linked List Sandboxes:** Real-time container manipulation with boundary traces.

## 🚀 Quick Start & Cross-Platform Terminal Access

### 💻 On Windows
```bash
git clone https://github.com/prajwalchonnad/OILS-3.git
cd OILS-3
# Double click play.bat OR run in PowerShell/CMD:
.\play.bat
```

### 🍎 On macOS & Linux
```bash
git clone https://github.com/prajwalchonnad/OILS-3.git
cd OILS-3
chmod +x play.sh
./play.sh
```

### 📱 On Mobile Devices (Android Termux / iOS iSH)
Run the companion directly in your phone terminal:
```bash
pkg update && pkg install git python -y
git clone https://github.com/prajwalchonnad/OILS-3.git
cd OILS-3 && python play.py
```
