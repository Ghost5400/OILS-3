The ultimate interactive terminal lab companion built specifically for VTU 
3rd Semester Computer Science engineering students. No boring theory walls, 
no robotic memorization — learn every lab experiment end-to-end with visual 
intuition, ASCII memory sandboxes, disaster recoveries, and viva drills!


================================================================================
📂 REPOSITORY STRUCTURE (WHAT YOU SEE IN THIS FOLDER)
================================================================================
To keep things super clean and non-intimidating for students, the main folder 
contains ONLY direct launchers and info files:

• play.bat        -> Double-click to launch on Windows (Easiest!)
• play.sh         -> Launch script for macOS, Linux, and Mobile terminals
• play.py         -> Python entry point
• open_me.txt     -> Quickstart guide & syllabus catalog (this file)
• about_us.txt    -> The creators & project origin
• For_Developers/ -> Internal engines, source code, lab programs & docs


================================================================================
🚀 HOW TO RUN THIS INTERACTIVE COMPANION ON YOUR DEVICE
================================================================================

💻 OPTION 1: ON WINDOWS LAPTOP / PC (EASIEST)
--------------------------------------------------------------------------------
1. Double-click the file named:
      play.bat
   (Or open Command Prompt / PowerShell in this folder and run: .\play.bat)

2. If you prefer running directly with Python:
      python play.py

--------------------------------------------------------------------------------
🍎 OPTION 2: ON macOS & LINUX LAPTOP / PC
--------------------------------------------------------------------------------
1. Open your Terminal inside this folder.
2. Run the launcher script:
      chmod +x play.sh
      ./play.sh

   (Or run directly: python3 play.py)

--------------------------------------------------------------------------------
📱 OPTION 3: ON MOBILE DEVICES (ANDROID / iOS) VIA TERMINAL
--------------------------------------------------------------------------------
You can run this full terminal arcade on your smartphone without a laptop!

A) Android (via Termux - Free on F-Droid / GitHub):
   1. Open Termux and paste this quick one-liner:
         pkg update && pkg install git python -y
         git clone https://github.com/Ghost5400/OILS-3.git
         cd OILS-3 && python play.py

B) iOS / iPad (via iSH Shell or a-Shell from App Store):
   1. Open iSH Shell and run:
         apk add python3 git
         git clone https://github.com/Ghost5400/OILS-3.git
         cd OILS-3 && python3 play.py

--------------------------------------------------------------------------------
🌐 OPTION 4: ZERO INSTALLATION IN BROWSER (ANY DEVICE VIA CLOUD TERMINAL)
--------------------------------------------------------------------------------
Don't want to install Python or anything on your computer or phone?
You can run the genuine Linux terminal version directly inside your web browser:

1. Visit our GitHub repository:
      https://github.com/Ghost5400/OILS-3
2. Click the green "Code" button -> select "Codespaces" tab -> "Create codespace".
3. A real terminal opens right in your browser (Chrome/Safari/Edge/Firefox) and 
   automatically starts OILS-3! Zero setup required.
